# Karta državnih šuma

PWA karta državnih šuma (Hrvatske šume d.o.o.) i zastupljenosti vrsta drveća po gospodarskim jedinicama.

Izvor podataka: Hrvatske šume d.o.o., javni podaci (webgis.hrsume.hr, Obrazac O-4 iz šumskogospodarskih planova).
Podloge: Esri. Za branje nedrvnih šumskih proizvoda potrebna je dozvola: https://nsp-dozvola.hrsume.hr/
